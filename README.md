# Mutual Fund Analytics & Interactive Dashboard Development

## Project Overview

This capstone project focuses on building an end-to-end Mutual Fund Analytics solution using Python, SQLite, and Power BI. The project includes data extraction, cleaning, exploratory data analysis (EDA), advanced analytics, risk assessment, investor behavior analysis, and dashboard visualization.

## Project Objectives

- Develop a complete ETL pipeline for mutual fund datasets.
- Clean and preprocess data using Python and Pandas.
- Store processed data using SQLite.
- Perform Exploratory Data Analysis (EDA).
- Calculate important financial metrics such as Sharpe Ratio, VaR, and CVaR.
- Analyze SIP trends and investor behavior.
- Build an interactive Power BI dashboard.
- Generate advanced analytics reports and recommendations.
